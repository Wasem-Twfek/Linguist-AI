## Main rules
- Do not invent features that are not implemented in the code.
- Clearly mark incomplete features as partially implemented or planned.
- Separate the work by student role.
- Do not repeat the same analytical part for all students.
- Use real file paths, components, routes, tables, and functions from the repository.
- The current stable AI implementation uses Google Gemini API.
- Alternative AI model support is only a test/future direction unless implemented in code.
- The main target audience is teachers and students of language courses and additional education organizations.
- Schools, universities, and self-study are only possible future adaptation areas.
